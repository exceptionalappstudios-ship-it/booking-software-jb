# Gurudev Ashram Appointment, Seva & Access Management System

Appointment + identity + QR + zone access control + gate management + dashboards + reporting
for Gurudev's Ashram visits (first event: Gujarat Ashram, 6–12 November 2026).

Stack (planned): Next.js (App Router, TypeScript) · Supabase (Postgres, Auth, Realtime, Storage) · Vercel · PWA scanner.

**Current status:** design proposal. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the
architecture, database schema, screen structure and phased implementation plan.
